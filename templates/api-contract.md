# API Contract

- Version: `<v1>`
- Method / path: `<GET|POST /resource>`
- Request: `<headers, params, query, body schema>`
- Response: `<status, body schema, pagination>`
- Error: `<status, stable code, message shape>`
- Time format: `<ISO 8601 UTC 또는 명시된 형식>`
- Null semantics: `<null 허용과 생략 의미>`
- Auth: `<인증 방식, actor, 권한>`
- DB constraints: `<FK, unique, check, policy>`
